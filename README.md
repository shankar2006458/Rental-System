# 🚗 Rental System

A simple and user-friendly web application to manage vehicle rentals, track bookings, and organize rental records.

## 🌐 Live Demo

[**Open Rental System**](https://shankar2006458.github.io/Rental-System/)

## ✨ Features

- 🚘 Manage rental records
- 📅 Track rental dates and returns
- 💰 Calculate rental charges
- 🔒 Track security deposits
- 📋 Keep rental information organized
- 📱 Simple and responsive user interface

## 🚀 Getting Started

1. Open the [Live Demo](https://shankar2006458.github.io/Rental-System/).
2. Start managing your rental records.
3. Use the available features to track rentals and payments.
